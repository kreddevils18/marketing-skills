# shared-rules.md template

Copy into `marketing/shared-rules.md`, then confirm or edit each rule with the
user. Keep it to rules that hold for every brand. Brand-specific rules belong in
that brand's Taste Profile.

```markdown
---
updated: YYYY-MM-DD
---

# Shared rules

_Applies to every brand. A Taste Profile only records what differs from this page.
When asking an AI to write, give it three things: this page, the brand's Taste
Profile, and the campaign brief._

- **Real numbers only.** Every number comes from the user or an analytics tool,
  with source and date. No number available: leave `[ ]`, never estimate.
- **No hype.** No promised results, no exaggeration. Banned: empty openers
  ("In today's AI era…", "Let's dive in…"), superlatives without a number
  ("game changer", "revolutionary", "10x"), stacks of emoji and hashtags,
  clickbait thread hooks ("99% of people don't know…").
- **Language.** Published content is in [language] unless a profile says
  otherwise.
- **References are skeletons.** Borrow structure from other creators, never
  sentences.
- **Never mention:** [products, clients or topics kept private].
- **Human review.** Nothing AI-written is published before [owner] approves it.
```

Ask the user about each bracket. If they have no private topics, delete that
line instead of leaving it empty.
