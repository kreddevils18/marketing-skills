# Content review checklist

Use for both drafting and reviewing. Check each item against the actual files;
quote the rule that a failing line breaks and give a rewrite.

## Shared rules and profile

- [ ] Every number is real, with a known source; placeholders stay as `[ ]`.
- [ ] No banned phrase from `shared-rules.md` or the profile's Guidelines.
- [ ] Nothing from the "never mention" list.
- [ ] Person, register and language match the profile's Voice.
- [ ] Reads like the profile's sample lines more than like its "wrong voice"
      examples.

## Campaign fit

- [ ] Carries the brief's one message; no second idea competing with it.
- [ ] Points to the brief's offer when the post asks for an action.
- [ ] Speaks to the brief's audience slice and one of its pains.
- [ ] Uses a format and hook style planned in Tailor, or says why not.
- [ ] Call to action moves the campaign's target metric.
- [ ] Every link carries the campaign UTM.

## Craft

- [ ] The first line works alone as the hook: a number, a claim or a discovery.
- [ ] One idea per post; threads only when each part earns its place.
- [ ] Specific beats general: a named product, a measured result, a date.
- [ ] Fits the channel's length and conventions (no hashtags on X unless the
      profile allows them).

## Output

Return failing items only, most important first, each with the rule, the line
and a rewrite. If everything passes, say so in one line and suggest one optional
improvement.
